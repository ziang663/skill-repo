# skill-repo

Repository-scoped Codex skills live under `.agents/skills/`.

| Skill | Purpose |
|---|---|
| `model-forward-trace-analysis` | Trace and explain SGLang model forwards, GPU kernels, communication, and dtype boundaries. |
| `siflow-llm-ops` | Install the SiFlow SDK and safely operate or diagnose SiFlow LLM services. |
| `siflow-image-factory` | Build SiFlow engine/router images through the SDK, track provenance, and validate image contents, FlashBoot caches, and cross-cluster builds. |
| `local-feishu-agent-deploy` | Securely deploy, validate, restart, and troubleshoot a local Feishu/Lark agent backend. |
| `llm-throughput-revenue-eval` | Plan local SGLang throughput and SLA-constrained TPM tests, verify cache-aware official prices, and estimate per-GPU monthly revenue; includes the five-model H200 plan. |
